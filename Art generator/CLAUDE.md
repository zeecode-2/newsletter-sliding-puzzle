# CLAUDE.md — Project Instructions

## Git & Version Control

Commit and push to GitHub regularly throughout all work — after every meaningful change, not just at the end of a session. This ensures no progress is ever lost.

**When to commit:**
- After creating or significantly modifying a file
- After a feature or section is working
- Before making any large refactor
- After fixing a bug

**Commit message format:**
- `feat: short description` — new feature or capability
- `fix: short description` — bug fix
- `chore: short description` — dependencies, config, tooling
- `docs: short description` — documentation only

Keep messages concise and specific (e.g. `feat: add geo SEO tab to output panel`, not `update files`).

**Push after every commit.** Do not batch multiple sessions of work into one push.
